# Equity — Stock Trading Platform UI

A React portfolio dashboard demonstrating stock watchlists, portfolio holdings, search, asset selection and simulated buy/sell interactions.

## Features
- Stock watchlist with search and selected-stock details
- Portfolio value and summary cards calculated from holdings
- Simulated buy and sell order modal
- Holdings table updates after demo trades
- Responsive dashboard layout

## Tech
React, JavaScript, Vite, CSS and Lucide icons.

## Run
```bash
npm install
npm run dev
```

## Important scope note
This is a frontend portfolio prototype using static sample prices and in-memory state. It does not connect to a brokerage, live market feed, authentication, backend API or database. Trades reset when the page reloads.
